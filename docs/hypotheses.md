# План исследования, зафиксированный до расчёта результатов

Дата подготовки: 28 октября 2026. Это учебное исследование открытых исторических данных Olist, не исследование Авито.

## Решение для продукта
Определить, заслуживает ли улучшение опыта доставки отдельного продуктового эксперимента, и выбрать сегмент/сценарий для следующего исследования.

## Разделение данных
- Разведочный период (discovery): покупки с 2017-01-01 до 2018-07-01, правая граница не включается.
- Проверочный период (validation): покупки с 2018-07-01 до 2018-09-01.
- Более ранние и более поздние месяцы не входят в основное сравнение: на краях выгрузки мало заказов и возможна незавершённость статусов.
- Для статистических тестов берём первый пригодный доставленный заказ каждого customer_unique_id в соответствующем периоде. Это первый наблюдаемый пригодный заказ периода, а не гарантированно первая покупка клиента за всю историю.
- Повторные заказы используются в описательном EDA; независимость статистических наблюдений от повторных заказов обеспечивается отдельным отбором. Общие продавцы всё ещё могут создавать зависимость; для H1 предусмотрен кластерный bootstrap по продавцам на заказах с одним продавцом.

## Определения
- Срок доставки: календарное время от покупки до фактической доставки, в дробных днях.
- Опоздание: дата фактической доставки строго позже обещанной даты. Доставка в любой час обещанного календарного дня считается своевременной.
- Низкая оценка: 1 или 2 из 5. Знаменатель — заказы с пригодным первым отзывом, а не все заказы.
- Для основной проверки H1 используется первый ответ покупателя на опрос по заказу, если ответ дан после фактической доставки и не позднее 30 дней после неё. Более ранние ответы, отсутствие отзывов и поздние ответы учитываются отдельно. Это анализ только ответивших покупателей.

## Основные гипотезы: одна семья из трёх проверок
H1. Доля низких оценок различается у доставленных вовремя и опоздавших заказов. Ожидаемое направление: у опоздавших выше. Двусторонний z-тест двух долей, разность долей и 95% интервал Ньюкомба на основе интервалов Уилсона.

H2. Средний срок доставки различается у заказов внутри одного штата и между штатами. Двусторонний t-тест Уэлча и интервал разности средних. Маршрут определяем только для заказов с одним продавцом.

H3. Средний срок доставки различается между тремя самыми массовыми штатами назначения в discovery. Список штатов выбирается только по численности discovery и замораживается до validation. ANOVA Уэлча, допускающая неодинаковые дисперсии. Она не устанавливает, какие именно пары отличаются.

Для трёх основных p-value применяем поправку Холма при alpha=0.05. Указываем численность, размер различий и ограничения. Положительный статистический результат означает связь в наблюдаемых данных, а не доказательство причинного эффекта продуктового изменения.

## Дополнительные диагностики и проверки устойчивости
- Шапиро — Уилка и Q–Q: только discovery, воспроизводимая подвыборка до 5000 сроков доставки. Не использовать p-value как автоматический переключатель выбора теста.
- Двухвыборочный Колмогорова — Смирнова: сравнение формы распределений сроков доставки внутри/между штатами только в discovery. p-value носит разведочный характер; одинаковые округлённые значения могут нарушать условие непрерывности.
- H1: включить все первые отзывы, включая отправленные до доставки/позднее 30 дней; сравнить с основной выборкой.
- H1: стандартизовать разность долей по месяцу покупки и штату покупателя, оставить общие страты с минимум 10 заказами в каждой группе; описать долю покрытых заказов.
- H1: кластерный bootstrap разности долей на заказах с одним продавцом; 2000 повторов, seed=42. Повторно выбираем продавцов вместе со всеми их заказами.
- Не обрезать длинные доставки автоматически: длинный срок может быть реальным. Ошибочный порядок дат исключается явно и отражается в отчёте.

## Дополнительная ML-задача
Оценка риска опоздания в момент подтверждения оплаты. Target — поздняя доставка. Признаки должны быть известны не позже подтверждения оплаты: цена, стоимость доставки, состав заказа, штаты, категория, обещанный оставшийся срок. Фактическая доставка, отзывы, фактический срок и признак опоздания в признаки не входят.

Обучение: до июля 2018; выбор модели: июль; финальная проверка: август. Каждый покупатель включается только один раз, по первому пригодному заказу во всём ML-периоде. Сравнение DummyClassifier и LogisticRegression. Метрики: ROC-AUC, Average Precision и precision/recall при бюджете 10% заказов. Оценка по августу не используется для подбора модели. Модель не доказывает, что обработка рискованных заказов улучшит опыт доставки.

## Продуктовое продолжение
Приоритизировать гипотезу по сочетанию размера связи, числа затронутых заказов, выполнимости и неопределённости. Следующий шаг — план эксперимента, а не заявление о внедрённом улучшении. Для плана указать основную метрику, защитные метрики, единицу рандомизации, MDE и требуемую выборку.
